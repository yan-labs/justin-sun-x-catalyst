# Ecosystem map - Justin Sun topics to tradable reaction baskets

## Purpose

Map Justin Sun X topics into candidate reaction assets. Treat this as a watchlist
and routing table, not as a recommendation list. Always confirm that an asset is
liquid, supported by the user's quote provider, and appropriate for the user's
account before discussing any manual trade.

## Core TRON ecosystem

**TRX / TRON network**
- Triggers: TRON, TRX, USDT settlement, stablecoin rail, fees, active addresses,
  governance, upgrades, post-quantum claims, treasury accumulation.
- First read: TRX direction.
- Second read: Nasdaq TRON if it remains a TRX-treasury proxy; broader crypto
  beta if the message is macro.

**JST / JUST / JustLend**
- Triggers: JST, JUST, JustLend DAO, burn mechanism, lending, collateral,
  "new TRX" framing.
- First read: JST.
- Second read: TRX if the message expands into TRON DeFi utility.

**SUN / SunSwap / SunPump / meme launchpad**
- Triggers: SUN burn, SunSwap, SunPump, meme launch, launchpad volume, fair
  launch, perpetual DEX.
- First read: SUN or named memecoin.
- Second read: TRX for gas/attention.
- Caveat: most launchpad/memecoin reactions are low-durability.

**BTT / BitTorrent / Rainberry**
- Triggers: BTT, BitTorrent, Rainberry, file sharing, SEC settlement, legacy
  corporate actions.
- First read: BTT when liquid.
- Second read: TRX only if the post links the issue to TRON.

**USDD**
- Triggers: USDD, reserve, collateral, peg, stablecoin, Tron DAO Reserve.
- First read: TRX and USDD confidence.
- Risk read: any peg, reserve, or collateral concern is a risk-off signal.

  participation is visible.

## Direction rules

- Praise/support/buyback/listing/burn: primary asset up first.
- Lawsuit/freeze/security/reserve concern: named target down first.
- Stablecoin settlement growth: TRX up if metrics are credible.
- Memecoin launch/political dinner: attention up, durability low.
- WBTC custody concern: WBTC/DeFi collateral risk-off, not necessarily BTC down.
- Generic market commentary: broad crypto beta, low confidence for TRX.
